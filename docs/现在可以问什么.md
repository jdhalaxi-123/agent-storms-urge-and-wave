## 一、每日预报（当天在更新的那批）

```
今天厦门的风暴潮什么情况          ← 会如实说“今天(0916)预报尚未更新，用的是 0915 起报”
厦门明天的增水多大，会不会超预警线
崇武 / 晋江 / 东山东港 的增水
9月20日厦门的风暴潮
福建沿海的增水分布                ← 出区域分布图 + 峰值位置 + 分级格点数
台湾海峡的海浪多大
画一下今天的风场                  ← 每天更新的风场（据实说明：首次取数约 30~60 秒）
厦门今天的数据更新了吗
```

## 一点五、出图（问什么画什么，不多给）

图型已对齐课题三投产图风格（cartopy 真海岸线 + jet 配色 + 等级线）：

```
画一下福建沿海的风场              ← 风速填色 + 风矢 + 7/10 级等值线（13.9 / 24.5 m/s）
看看台湾海峡的海浪场              ← 浪高填色 + 海况等级线（小浪~怒涛）
画个风浪双联图                    ← 左风速右浪高，业务常用合成图
来个风场动图                      ← GIF（约 10 秒）
2403 的预报和实测对比             ← 密度散点 + RMSE/Bias/R（台风个例有实测时才出）
看看福建沿海的场的情况            ← 区域增水空间分布 + 峰值位置
```

**小区域自动用精细网格**：问闽南 / 厦门 / 泉州这类小范围（跨度 ≤4°）的增水分布时，
系统自动切到课题三的 **0.01° 精细增水场**（`surge_predicted_*.nc`，约 1 km，
覆盖 116.7~120.3°E / 23.83~25.17°N），不再是一格一格的 0.25° 方格；
大区域（福建、台湾海峡、东南沿海）仍用 0.25° 场，海浪目前只有 0.5° 网格。

`plot` 取值：`wind` 风场 / `surge_station` 站点曲线 / `surge_field` 全场增水 /
`wave` 海浪曲线 / `wind_wave` 风浪双联 / `gif` 动图 / `validation` 实测对比 / `all` 全部。

## 六、现在**问不了**的（agent 会如实说明，不会编）

| 问什么 | 为什么 |
| --- | --- |
| 总水位超不超警戒潮位、会不会海水倒灌 | **缺天文潮**。只能判“增水”级别（30/50/80/120 cm），判不了对照四色警戒潮位的总水位 |
| 上海 / 青岛 / 深圳 / 海口 / 香港 | 覆盖范围外，只回文字说明，不出数据 |
| 数值 + AI + 融合 对比 | FTP 上融合产品不存在（只有 239 字节空文件） |
| 浮标站的经纬度定位 | 数据里只有站号（C6W10 等），没有“站号↔经纬度”对照表 |
| 1960–2020 年的长序列气候统计 | 每日预报从 2015-07-27 起才有 |
