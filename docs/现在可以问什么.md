## 一、每日预报（当天在更新的那批）

```
今天厦门的风暴潮什么情况          ← 会如实说“今天(0916)预报尚未更新，用的是 0915 起报”
厦门明天的增水多大，会不会超预警线
崇武 / 晋江 / 东山东港 的增水
9月20日厦门的风暴潮
福建沿海的增水分布                ← 出区域分布图 + 峰值位置 + 分级格点数
台湾海峡的海浪多大
画一下今天的风场                  ← 每天更新的风场（据实说明：首次取数约 30~60 秒）
厦门今天的数据更新了吗
```

## 二、需求澄清（先说清楚再干活）

```
帮我看看风暴潮                    ← 先问 3~5 个带选项的问题，这一轮不取数
厦门，明天，主要看增水会不会超警戒，要过程曲线   ← 一句话答完，直接出结果
别问了，直接给                    ← 跳过追问，按默认值出结果
```

## 六、现在**问不了**的（agent 会如实说明，不会编）

| 问什么 | 为什么 |
| --- | --- |
| 总水位超不超警戒潮位、会不会海水倒灌 | **缺天文潮**。只能判“增水”级别（30/50/80/120 cm），判不了对照四色警戒潮位的总水位 |
| 上海 / 青岛 / 深圳 / 海口 / 香港 | 覆盖范围外，只回文字说明，不出数据 |
| 数值 + AI + 融合 对比 | FTP 上融合产品不存在（只有 239 字节空文件） |
| 浮标站的经纬度定位 | 数据里只有站号（C6W10 等），没有“站号↔经纬度”对照表 |
| 1960–2020 年的长序列气候统计 | 每日预报从 2015-07-27 起才有 |
