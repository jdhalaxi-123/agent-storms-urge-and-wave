## 三、开工前会先把需求问清楚（需求澄清）

**只要你的问题里有说不清的地方，助手不会猜着给结果，而是先问 3~5 个带选项的问题**，
你一句话甚至一个词就能答完，然后它再出数据。

**会问的 5 个方面**

| 槽位 | 例子里的选项 |
| --- | --- |
| ① 看哪里 | 厦门 / 崇武 / 晋江 / 东山东港；或福建、台湾海峡等区域；或经纬度 |
| ② 看什么时间 | 今天 / 明天 / 未来几天 / 某个历史台风 |
| ③ 数据口径 | 当天的每日预报，还是历史台风个例 |
| ④ 关心什么 | 增水多大 / 总水位超不超警戒潮位 / 浪高多少 / 会不会海水倒灌 |
| ⑤ 要不要图 | 站点过程曲线 / 全场增水分布 / 风场 / 海浪曲线 |

**实例**

```
【问】帮我看看风暴潮
【答】风暴潮我可以帮你查，先确认几个信息，免得给错结果：
      1. 看哪里：厦门 / 崇武 / 晋江 / 东山东港（或福建沿海、台湾海峡等区域）？
      2. 看什么时间：最新一次每日预报（2026-09-15 起报，覆盖未来 7 天）/ 某个历史台风个例？
      3. 关心哪方面：增水多大 / 总水位会不会超警戒潮位（海水倒灌风险）/ 预警等级？
      4. 要不要图：站点过程曲线 / 全场增水分布 / 风场？
      也可以直接说「你看着给」，我就按默认值（厦门、最新每日预报、风暴潮增水）出结果。
      —— 这一步不会去取任何数据，答完才查。

【问】厦门，明天，主要看增水会不会超警戒，要过程曲线
【答】（直接把前后两轮的信息合起来查，不再重复确认）
```

**几条规则**

- **只问缺的**：你已经说清的不会再问，能从上文推断的直接沿用；
- **选项都是真的**：问题里的站点、台风编号、日期范围都取自系统当前真实可查的范围，
  不会问你一个查不到的东西；
- **先问再算**：追问的那一轮**不取数、不出图**，你答完才执行；
- **想跳过就说**：说「别问了 / 直接给 / 你看着给」，助手就按默认值
  （区域=厦门、时间=最近一次每日预报、灾种=风暴潮）直接出结果；
- **大范围不追问**：问「福建的风暴潮」「台湾海峡的海浪」这类区域，系统会直接给
  **区域面预报**（空间分布图 + 区域峰值位置 + 分级格点数），不再回头问你。

## 五、暂时查不了的（如实说明）

| 想查的 | 为什么不行 | 缺什么 |
| --- | --- | --- |
| **当日/未来预报** | 现有数据都是**历史台风回算**；每日预报流程停在 2026-05-31 | 需要连续的天文潮预报（或潮汐调和常数）+ 恢复每日预报 |
| **总水位的绝对判级** | 模式输出水位的**基准面**（平均海面 / 水尺零点）尚未确认，与警戒潮位的 85 黄零基准可能差一个常数 | 需要厦门中心提供各站基准关系 |
| **海浪的空间分布图** | 波浪场文件单个 **2.7 GB**，按需下载不现实 | 需要波浪场的裁剪版或格点化产品 |
| **浮标站的经纬度定位** | 波浪单点/实测文件里**只有站号**（如 C6W10），没有经纬度 | 需要「站号 ↔ 站名 ↔ 经纬度」对照表 |
| **潮位站的站名** | 33 个潮位站只有数字编号（112、1102、C4W05…） | 同上，需要对照表 |
| **数值 vs AI vs 融合 对比** | 融合产品**尚未产出**（`/group5/fusion/` 只有 239 字节空文件） | 等融合产品上传 |
