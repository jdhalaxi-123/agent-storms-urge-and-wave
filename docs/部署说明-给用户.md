## 三、部署步骤

### 第 1 步　解压部署包

把 `stormsurge-agent-部署包-YYYYMMDD.zip` 解压到一个**全新文件夹**（建议路径不含空格与特殊符号），例如：

```
D:\stormsurge-agent
```

> ⚠️ 请勿在旧版本目录上覆盖安装，也请勿重复解压出多个同名目录（容易启动到旧程序）。

### 第 2 步　配置 API Key 与 FTP

1. 在该目录下找到 `.env` 文件（没有的话，把 `.env.example` 复制成 `.env`）；
2. 用记事本打开，按下表填入第 2 章的配置；
3. 保存为 UTF-8，关闭记事本。

也可以直接双击 `5-配置FTP.bat`：它会自动打开 `.env` 并提示填哪四行，保存后自动测试连接。

### 第 3 步　一键部署

双击根目录的：

```
1-一键部署.bat
```

脚本会自动完成：

1. 检查并安装 Python（若本机没有）；
2. 创建虚拟环境 `.venv`；
3. 安装全部依赖（含绘图所需的 cartopy、地图库、数据处理库等，约 1.5 GB，首次 5~20 分钟）；
4. 生成桌面快捷方式。

> 若卡在下载依赖：多为系统代理未开启所致（报错含 `ProxyError`），部署脚本已自动绕过；仍失败请双击 `7-一键修复.bat`。

### 第 4 步　自检（强烈建议）

双击：

```
7-一键修复.bat
```

它会依次检查并给出成绩单（同时写入 `修复日志.txt`）：

```
⓪ 代码版本      ✅ 含下载失败修复（新代码）
① 代理          ✅ 已清空失效代理
② 依赖          ✅ 缺什么装什么
③ 取数（FTP）   ✅ 实测下载一个小文件
④ 出图          ✅ 实测画一张带中文标题的小图
```

**四项全绿**即可正常使用；出现 ❌ 时请把 `修复日志.txt` 内容发技术人员。

### 第 5 步　启动

双击：

```
2-启动.bat
```

浏览器打开 <http://localhost:7860>。启动窗口会打印版本号与运行目录，可用于确认跑的是哪一份程序。

### 第 6 步　（可选）设置每日自动下载

双击：

```
4-设置自动下载.bat
```

注册计划任务后，程序每 30 分钟检查一次课题组数据库，有新一期数据自动下载缓存。

## 五、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 双击 `.bat` 一闪而过没反应 | 脚本换行符或编码问题，请使用最新部署包；也可右键"以管理员身份运行"重试 |
| 提示 `ProxyError / Cannot connect to proxy` | 本机设置了系统代理但代理未启动：双击 `7-一键修复.bat`（会自动清空代理后再装） |
| 提示端口 7860 被占用 | 有旧的程序实例在运行：先结束所有 `python.exe`，再启动；或设 `STORM_PORT=7861` 后启动 |
| 能回答但出不来图 | 优先双击 `7-一键修复.bat`；若报"下载失败"，看 `修复日志.txt` 里的原因（网络或 FTP 侧） |
| 取数报"文件不存在" | 多为下载未成功的旧版现象，请使用含"下载失败修复"的新版本 |
| 浏览器看不到图 | 检查界面库版本需为 5.x（`pip install "gradio>=5.0,<6.0"`） |
| 语音输入没反应 | 属可选项：填腾讯云密钥，或安装本地识别包；文字问答不受影响 |
| 想换台机器 | 重复第二章填写配置 + 第三章步骤即可；数据会自动缓存到新机器的 `stormdata/` |

## 七、卸载

双击 `6-卸载-Windows.bat`，按提示输入 `YES` 确认。它会清理：

1. 正在运行的服务进程；
2. 计划任务（若设置过自动下载）；
3. 桌面快捷方式；
4. 整个程序目录（含 `.env` 配置与已下载数据）。

> 随部署安装的 Python 若不再需要，可在"设置 → 应用 → 已安装的应用"中单独卸载。
