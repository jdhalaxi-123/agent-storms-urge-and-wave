## 三、那个助手需要什么（给你对照用）

**必需**
- **风暴潮**：增水场（或 总水位 + 天文潮，两者相减得增水），要有时间维
- **海浪**：有效波高（hs），要有时间维

**可选但有用**：风场（u10/v10 或 风速/风向）；站点单点序列（含站点经纬度）

**空间形式**：规则网格（time×lat×lon）或非结构三角网格（节点经纬度 + 三角形表）**都支持**

**时间形式**：datetime64 或「数字 + 单位 + 基准日」**都支持**（但基准日必须说清楚）

**数据目录约定**（助手默认扫描程序目录下的 `data/`，也可指定别的位置）：
```
data/
├── <台风编号>/                   例：2526/   数值场、AI/融合场
├── Ensemble/                     集合（AI）预报
├── ftp/<台风编号>/               从课题数据库同步下来的
└── typhoon_<台风编号>-wave/      海浪场（细网格 + 大范围网格）
```

**判级口径**：有本站警戒潮位表 → 按「总水位 × 四色警戒潮位」；没有 → 按「风暴增水分级」
（蓝 30cm / 黄 50cm / 橙 80cm / 红 120cm）。请判断这边的数据够不够支撑判级。

## 五、约束（务必遵守）

1. **只报告实际存在的路径**，不要推测、不要"应该是这里"。找不到就写"未找到"。
2. **只读，不要修改、删除、移动任何文件**。
3. **不要执行预报运算**（除非用户明确同意）；不要跑可能占满 CPU/磁盘的命令。

5. 不确定的地方**明确标注"不确定"**，并说明还需要用户补充什么。
