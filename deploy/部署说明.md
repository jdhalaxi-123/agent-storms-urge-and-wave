# 部署说明（一键部署 · 在线安装版）

> 面向对象：拿到交付包、要把它装到**另一台电脑**上的人。
> 全程不需要懂编程，照着做就行。

---

## 一、包里面有什么

```
stormsurge-agent/
├── 1-一键部署-Windows.bat   ← 双击这个就开始装（Windows）
├── 2-启动.bat               ← 装完之后，以后启动就双击这个
├── 3-环境自检.bat           ← 装不上时先跑这个，生成报告给 AI 看
├── 部署说明.md              ← 本文件
├── requirements.txt         ← 依赖清单
├── .env.example             ← 密钥模板
├── main.py                  ← 程序入口
├── orchestrator/            ← 编排层（LLM / 引擎 / 记忆 / 覆盖范围判定）
├── modules/                 ← 业务模块（取数 / 统计 / 判级 / 简报 / 出图）
├── scenarios/               ← 场景路由表
├── scripts/                 ← 辅助脚本（含样例数据生成）
└── deploy/                  ← 部署脚本本体
    ├── setup_windows.ps1     （1-一键部署 实际执行的逻辑）
    ├── setup_linux.sh        （Linux / macOS 用这个）
    ├── start_linux.sh
    └── check_env.py          （3-环境自检 实际执行的逻辑）
```

**本包不含数据**（数据有 8 GB 以上，单独拷贝）。
把 NC 数据放到程序目录下的 `data/` 即可，详见第五节。

## 二、Windows 一键部署（推荐）

### 第 1 步：解压

把压缩包解压到一个**路径里没有中文和空格**的位置，例如 `D:\stormsurge-agent`。

> 不推荐放桌面或 `C:\Program Files`：路径里有中文/空格时，个别依赖可能装不上。

### 第 2 步：双击 `1-一键部署-Windows.bat`

脚本会自动做这些事，**中途不要关窗口**：

| 步骤 | 做什么 | 大概耗时 |
| --- | --- | --- |
| 1 | 检查是不是 64 位系统、有没有 VC++ 运行库（缺了自动装） | 10 秒 ~ 2 分钟 |
| 2 | 找 Python；**没有就自动下载安装 Python 3.10** | 1 ~ 5 分钟 |
| 3 | 创建运行环境 `.venv` | 30 秒 |
| 4 | 下载安装依赖（约 1.5 GB） | **5 ~ 20 分钟** |
| 5 | 提示你输入 DeepSeek API Key | — |
| 6 | 检查数据目录 | — |
| 7 | 创建桌面快捷方式「风暴潮智能预报助手」 | — |
| 8 | 启动服务并自动打开浏览器 | 10 ~ 30 秒 |

### 第 3 步：填 DeepSeek API Key

装依赖到一半会停下来问你：

```
   请输入 DeepSeek API Key（必填，形如 sk-xxxxxxxx）
   获取地址：https://platform.deepseek.com   （直接回车可跳过，之后手工填 .env）
   DeepSeek API Key:
```

把 `sk-` 开头的那串贴进去按回车即可。

- 如果先按了回车跳过：装完后用记事本打开程序目录下的 `.env`，
  把 `DEEPSEEK_API_KEY=` 后面补上你的 Key，保存即可。
- 语音识别（腾讯云）不是必须的：不填会用本地识别模型，只是第一次说话时会先下载模型。

### 第 4 步：用起来

浏览器会自动打开 `http://localhost:7860`。
如果没自动打开，手动在浏览器输入这个地址。

**以后每次使用：双击 `2-启动.bat`**（或桌面上的「风暴潮智能预报助手」）。
关闭那个黑色窗口 = 停止服务。

## 三、装不上怎么办

### 先跑 `3-环境自检.bat`

它会生成一份《环境自检报告.md》，内容包括：

- 系统版本、是不是 64 位、有没有 VC++ 运行库
- 找到的 Python 及版本、pip 是否可用
- **能不能连通 pip 源和 api.deepseek.com**（还有延迟毫秒数）
- 磁盘剩余空间、7860 端口是否被占用
- 项目文件齐不齐、数据目录在不在
- 最后给一段 **JSON 格式的机器可读事实**

**看不懂就把报告全文复制给 AI**（比如另一台电脑上的 DeepSeek），
直接问它："这份报告说明什么、我下一步该怎么做？" —— 报告里的信息足够它判断。

### 可以直接复制给 AI 的提问模板

```
我拿到一个风暴潮预报系统的交付包，要在下面这台电脑上部署。
包里有 1-一键部署-Windows.bat / 2-启动.bat / 3-环境自检.bat 三个脚本，
底层是 Python 3.10 + gradio + xarray/netCDF4，用 pip 装依赖，服务跑在 7860 端口。

这是这台电脑的环境自检报告（3-环境自检.bat 生成的）：

<<<<<< 把《环境自检报告.md》全文粘贴到这里 >>>>>>

请告诉我：
1. 这台电脑能不能直接跑 1-一键部署-Windows.bat？
2. 如果不能，具体卡在哪一步、需要先装什么、给我可以照着敲的命令。
3. 部署完成后我怎么确认成功了。
```

报告末尾附了一段 JSON（系统、Python、pip 源连通性与延迟、磁盘、端口、数据目录），
AI 读那段 JSON 就够了，不会因为看不懂中文描述而误判。

### 常见问题

| 现象 | 原因 / 解决 |
| --- | --- |
| 卡在"下载依赖"很久 | 正常，1.5 GB。脚本会自动在清华/阿里/官方源之间切换 |
| 报 `netCDF4` 装不上 | 缺 VC++ 运行库。手动装：<https://aka.ms/vs/17/release/vc_redist.x64.exe> 后重跑 |
| 报连不上 pypi | 公司网络限制。让运维开放 `pypi.tuna.tsinghua.edu.cn` 或配代理；也可以改用离线包 |
| 浏览器打不开 / 打不开 http://localhost:7860 | 7860 被占用。`3-环境自检` 会告诉你是哪个；或设环境变量 `STORM_PORT=7861` 换个端口 |
| 对话回复"未找到 DEEPSEEK_API_KEY" | `.env` 没填或没保存，填完重启 |
| 第一次用语音输入卡很久 | 本地识别模型要从 HuggingFace 下载。国内可先设环境变量走镜像：<br>`set HF_ENDPOINT=https://hf-mirror.com` 再启动；或直接在 `.env` 里填腾讯云密钥走云端识别 |
| 问什么都答"数据不足/骨架演示" | 没有 `data/` 数据，见第五节 |
| 想换端口/让别人也能访问 | 启动前设置环境变量：`set STORM_PORT=8080`、`set STORM_HOST=0.0.0.0` |

## 四、Linux / macOS 部署

```bash
cd stormsurge-agent
bash deploy/setup_linux.sh                # 一键部署（可选 --mirror 指定 pip 源）
bash deploy/start_linux.sh                # 以后启动
```

如果 `netCDF4` 编译失败，先装系统库：

```bash
# Ubuntu / Debian
sudo apt update && sudo apt install -y python3 python3-venv python3-pip libnetcdf-dev libhdf5-dev
# CentOS / RHEL
sudo yum install -y python3 python3-pip netcdf-devel hdf5-devel
# macOS
brew install python@3.10 netcdf
```

## 五、放数据

程序会自动扫描**程序目录下的 `data/`**，无需任何配置。目录约定：

```
data/
├── 2526/                          ← 按台风编号分文件夹
│   ├── output_0.nc                （数值模拟风暴潮场）
│   ├── output_4.nc                （AI/融合风暴潮场）
│   └── ERA5/                      （风场，可选）
├── Ensemble/                      ← 集合（AI）预报
│   └── Ensemble_Surge_20250421/2403_irregular_new.nc
├── ftp/                           ← 从课题数据库同步下来的数据
│   └── 2403/2403_surge.nc
└── typhoon_2526-wave/             ← 海浪场
    ├── M1_wav_20251110.nc
    └── R1_wav_20251110.nc
```

两种放法：

1. **拷贝**：把原来的 `data` 整个文件夹拷到程序目录下。
2. **指路**（数据在别的盘、不想拷）：启动前设置环境变量
   ```
   set STORM_DATA_DIR=E:\数据\storm_data
   ```
   或直接写进 `.env`：
   ```
   STORM_DATA_DIR=E:\数据\storm_data
   ```

**没有数据也能启动**：系统会自动降级为骨架演示，链路不中断，只是出不了真实预报图。

## 七、安全提醒

- `.env` 里有 DeepSeek Key、腾讯云密钥、FTP 账号密码 —— **不要外发、不要提交 git**（已在 `.gitignore` 里）。
- 交付包里**不含** `.env`，密钥由使用者自己填。
- 服务默认只监听 `127.0.0.1`（只有本机能访问）。要让同一局域网其他人访问，
  启动前设 `set STORM_HOST=0.0.0.0`，但请注意这意味着同网段的人都能访问。
